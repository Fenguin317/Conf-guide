# 예배자 에티켓

![](/assets/notion/etiquette-1.png)

---

> 함께 **예배자 에티켓**을 지키며 하나님의 임재를 경험하는 특별한 시간이 되길 기대합니다!

1️⃣ 각 구역별 입장시간은 [2027 아이자야컨퍼런스 가이드북] 노션에서 확인합니다.

2️⃣ 메인홀 입장 시, 팔찌 착용을 확인하고 있습니다. DAY별 해당되는 일수에 맞는 팔찌를 착용합니다.

3️⃣ 구역 내 좌석은 선착순으로 배정되고, 안쪽부터 채워 앉아야 하므로 스탭들의 안내에 따라주시기 바랍니다.

4️⃣ 메인홀 퇴장 시, 앉았던 자리는 깨끗하게 정리해주시고 놓고 가신 물건이 없는지 확인해주시기 바라며, 스탭들의 안내에 따라 차례를 지키며 안전하게 퇴장해주시기 바랍니다.

5️⃣ 메인홀 내부에서는 물병만 반입이 가능하오니, 이외의 음식물과 음료는 반입을 금지합니다.

6️⃣ 핸드폰은 무음모드로 해주시고, 예배에 방해되는 과도한 [영상촬영]은 자제해주시기 바랍니다.

7️⃣ 기타 문의사항은 [2027 아이자야컨퍼런스 가이드북] 또는 안내 스탭들에게 문의해주시기 바랍니다.
