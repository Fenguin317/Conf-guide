# filemap

- `README.md`: one-line repo description (from the GitHub repo's initial commit)
- `CLAUDE.md`: commands and rules for agents
- `QUESTIONS.md`: decisions (Q1–Q9)
- `render.yaml`: Render Blueprint (free plan, dev testing only)
- `docs/SPEC.md`: goals, schema, API, definition of done
- `docs/DESIGN.md`: markup contract and theme A/B specs
- `docs/PLAN.md`: task list and status
- `docs/REPORT.md`, `docs/REPORT.pdf`: progress report for the team (Korean)
- `docs/reference/`: G2A/Notion reference screenshots and scraped Notion text (`notion/`)
- `docs/screens/`: build-time screenshots; `docs/screens/qa/` is the final QA set used in the report
- `public/assets/poster.jpg`: conference poster (hero image, font/palette source)
- `public/assets/logo.png`: header logo (white on transparent, 480×97, resized from the ministry's 2017 logo PNG)
- `data/`: `content.json` (committed); `admin.json` and `backups/` are gitignored
- `server/index.js`: HTTP server (`createServer()`): static `public/`, SPA fallback, `/api/*` routes, security headers, frame-ancestors (`FRAME_ANCESTORS`)
- `server/auth.js`: scrypt hash/verify, in-memory sessions, 12-char password minimum (`createAuth()`)
- `public/admin/edit-mode.css`: styles for the visual editor; `public/app.js` loads it only in edit mode (`/?edit` inside the /admin iframe)
- `server/store.js`: `DATA_DIR`, read/validate/atomic-write `content.json`; GitHub mode (commit per save, history, restore) or local backups (newest 20); version check for concurrent saves
- `server/set-password.js`: `npm run set-password` prompt → `data/admin.json`
- `public/`: guide frontend; `public/admin/` is the admin UI
- `public/index.html`: guide shell (fonts, base.css, `#theme` link, header/main/footer slots, aria-live region)
- `public/base.css`: structural CSS shared by both themes (reset, font stacks, column, safe areas, a11y)
- `public/app.js`: content fetch, theme/lang pick, hash router, renderer (markup contract), `UI` strings, copy
- `public/theme-g2a.css`: design option A (G2A-style) colours and typography
- `public/theme-apple.css`: design option B (Apple-style): light/dark tokens, frosted header, inset grouped lists
- `public/admin/`: admin UI (`index.html`, `admin.js` login + Form/JSON editor + save, `admin.css`)
- `test/server.test.js`: auth, validator, and HTTP integration tests (`npm test`)
